# Thayen's Portfolio Site

This is the source code for my personal portfolio site, [thayen.ca](https://thayen.ca).

It is a static site using Astro and Typescript to improve developer experience with iterating on the site and is hosted via Cloudflare Workers as static assets.

## Acknowledgements

This project uses AI to help with prototyping initial styles and page design and to create assets (some of which are later improved manually). The actual contents of the page are authored and reviewed by me (though sometimes exact wording is reviewed by AI).
