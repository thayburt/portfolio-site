# Site
- `thayen.dev`
A portfolio site for myself as I am starting my career search in development and IT.

## Design
Using Astro for the framework and aiming for a simple, elegant and minimalistic SPA design (with as much prerendering as possible). Preferring to use base HTML and CSS with no required javascript (the site should function with or without but may not be as beautiful/extra)

## Styling
Keep it light and simple, I want to keep the site fast, clean, and easy to read (focusing advertising me). Draw inspirations from sites like [https://www.gnu.org/](https://www.gnu.org/)
